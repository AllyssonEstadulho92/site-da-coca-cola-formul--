# V3.8 — Acesso à aplicação

Fluxo visível:

1. Introduzir um e-mail válido `@ilunion.es`.
2. Selecionar `Continuar`.
3. Se já existir acesso local neste browser, introduzir a palavra-passe da aplicação e selecionar `Entrar`.
4. Se for o primeiro acesso neste dispositivo, definir e confirmar uma palavra-passe exclusiva da aplicação e selecionar `Criar palavra-passe e entrar`.

A palavra-passe empresarial não é utilizada nem validada pela aplicação. O mecanismo continua a ser local/client-side e não substitui autenticação corporativa ou SSO.

A V3.8 também usa estratégia network-first para HTML, JavaScript e CSS quando existe ligação, para reduzir a permanência de versões antigas em cache depois de uma publicação GitHub Pages.
