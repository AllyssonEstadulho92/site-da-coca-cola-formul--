# Política do diretório de equipamentos

- Uma pasta por modelo/família.
- Fotografias devem corresponder ao equipamento identificado e ser autorizadas para uso no projeto.
- Preferir `front.jpg`, `side.jpg` e `plate.jpg` para imagens.
- Não guardar dados de clientes, SAP, credenciais, e-mails internos, backups ou documentação confidencial no repositório público.
- Em caso de dúvida de modelo, manter a imagem fora do repositório até validação por placa técnica.
